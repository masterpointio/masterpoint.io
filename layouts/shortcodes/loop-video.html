{{- /* loop-video A silent, looping demo clip that stays completely inert until the reader scrolls to it. Nothing is fetched on page load: the sources carry `data-lv-src` rather than a real `src`, and assets/js/lazy-video.js swaps them in, starts playback once the frame is on screen, and pauses it again as soon as it scrolls away or the tab is hidden. `data-lv-src` is deliberately not `data-src`: the site-wide Defer.js pass in partials/scripts.html claims `data-src` and calls `.load()` on whatever it reveals, which would restart playback underneath us. Encode the source with no audio track — nothing here unmutes the video. H.264 MP4 only: VP9/WebM saves ~15% but is not supported widely enough to justify carrying a second asset. Call it on a SINGLE line in markdown. `trunk fmt` runs prettier over content, which reflows a multi-line shortcode call and reads the closing `>}}` as a blockquote, which then fails the build. Params: src (required) path to the .mp4 poster (required) still frame shown before the video loads width (required) intrinsic pixel width of the encode height (required) intrinsic pixel height of the encode alt (required) what the clip shows, for screen readers caption (optional) visible caption below the frame; markdown is rendered */ -}} {{- $src := .Get "src" -}} {{- $poster := .Get "poster" -}} {{- $width := .Get "width" -}} {{- $height := .Get "height" -}} {{- $alt := .Get "alt" -}} {{- $caption := .Get "caption" -}} {{- range slice "src" "poster" "width" "height" "alt" -}} {{- if not ($.Get .) -}} {{- errorf "loop-video shortcode in %q is missing the required %q param" $.Page.Path . -}} {{- end -}} {{- end -}}
